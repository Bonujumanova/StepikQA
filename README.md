# Проект автоматизации тестирования интернет-магазина: <a href="https://www.sima-land.ru/">Сима-ленд</a> 

## Цель:

Провести функциональное тестирование полного бизнес пути маршрута "User Case Story": 
Прохождение всего бизнес пути интернет-магазина на примере добавления товара в корзину с установленными фильтровыми значениями, оформления доставки

## Общее описание проекта:

Проект выполнен на языке программирования

- Python 3.14.3 
- в операционной системе Linux дистрибутив Manjaro Linux
- PyCharm 2025.3.3 (Community Edition)
- Mozilla Firefox 149.0.2 (64-bit)

## Частное описание проекта:

Проект построен по модели POM (Page Object Model), что позволяет в дальнейшем использовать его как основу для построения новых тестов. Репозиторий содержит следующие директории и файлы:


Директории:

- *base* - содержит различные базовые методы:

    - получение текущего URL: get_current_url
    - валидация по строчному значению: assert_product_name
    - создания скриншотов окна браузера и сохранение: get_screenshot
  
- *pages* - хранит POM классы страниц c используемыми на странице
  
- *screen* - хранит скриншоты, создаваемые методом get_screenshot
  
- *tests* - содержит группу тестов, которые выполняют тестирование


Файлы:
- confest.py - содержит параметры pytest для запуска параметризированных тестов
- README.md - содержит описание данного проекта

### 1. Переход на главную страницу Сима-ленд и выбор категории товара:
    - Клик на опцию Категории товаров
    - Выбор категории товара
    
### 2. Выбор подкатегории  товара:
    - Выбор подкатегории товара 

### 3. Выбор подподкатегрии товара:
    - В фильтрах выбрать подаодкатегорию товара, которая хранит в себе все Карнавальные костюмы в тематике "Костюм Ведьмы"
    - Выбрать подподподкатегорию "Костюм Ведьмы"

### 4. Выбор товара по размеру, добавление в корзину:
    - Кликнуть на определенный размер костюма
    - Добавить товар в корзину

### 5. Переход в корзину:
    - Проверка корректности добаленного товара в корзину и имеющегося товара в корзине
    - Проверка итоговой цены
    - Переход на страницу оформления заказа

### 6. Ввод данных(ФИО, адрес, почта, номер телефона):
    - Выбор способа доставки
    - Заполнение поля Адрес, ФИО,номер телефона
    - Оформление доставки
    
### 7. Сохранение скриншота финальной страницы, после оформления заказа:
    - Скриншот содержит данные о заказе(Номер заказа, ФИО, адрес и дату доставки, контакты пользователя)
